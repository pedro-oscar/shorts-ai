# Termos de domínio em português no código

Os tipos e nomes de domínio no código usam o português do `GLOSSARY.md` (`Projeto`, `Lote`, `Corte`, `Roteiro`, `Etapa`, `Reel`…). O código técnico (infraestrutura, utilidades, integrações) fica em inglês. O domínio e a interface nasceram em português, e traduzir esses termos criaria um segundo vocabulário para manter em sincronia com o glossário. A interface é bilíngue (pt-BR e inglês) por arquivos de tradução, e os nomes no código não mudam com o idioma da interface.
